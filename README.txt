フロー合成×スムーズフローポンプ LP（v6・ソース分割版）
==============================================

フォルダ構成
  index.html        ページ本体
  css/style.css     スタイル（PC・スマホのレスポンシブ含む）
  js/main.js        ボタンのスクロール、紹介動画の再生ON/OFF・進行バー、スマホ固定ボタン
  images/           写真・図版
  video/            紹介動画（tacmina_flow_synthesis.mp4／1280×720・約2分43秒・ナレーション入り）

公開のしかた
  ・フォルダごとサーバーに置き、index.html を開いてください（相対パス参照のため構成は変えずに配置）。
  ・書体は Google Fonts をオンラインで読み込みます。

差し替えが必要な箇所（［差し替え予定］と表示）
  ・実績のフラッシュ／固定触媒の写真枠 → 現場撮影の送液映像・写真
  ・ラインアップ（ラボ／ベンチ／生産）の製品写真 → 構成案の画像を仮置き。高解像度写真と製品名
  ・紹介動画 → ナレーション収録後に音声入りへ差し替え（video/ 内のファイルを同名で置き換え）
  ・ボタンのリンク先は未設定
